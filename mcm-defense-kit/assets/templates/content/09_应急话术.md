# 九、线上答辩应急话术（按场景查表）

> **用法**：把这一页单独打印，压在键盘旁边。**出事的时候不要思考，直接念。**
> 括号里的〔〕要提前替换成你们自己的数字和事实。

---

## 9.1 被问不会的问题

| 情形 | 话术 |
|---|---|
| **是代码问题** | "这个问题涉及**代码实现细节**，我们的编程手更清楚，请他来回答。" |
| **是模型问题，框架清楚但细节忘了** | "这个问题的核心是……（说框架）。**具体数字我打开文件核对一下。**" |
| **真的完全不会** | "老师，**这个问题我们目前的理解是……**（说你知道的部分）。**如果理解有偏差，还请老师指正。**" |
| **三个人都不会** | "这个问题我们**确实没有深入考虑**，感谢老师指出。**我们能确认的是：〔填：一个可验证的事实〕。**" |
| **被追问"你到底懂不懂"** | "模型和思路我们是清楚的；**〔填：具体薄弱的环节〕，实现细节我们理解得不深**。但结果是可以独立复核的。" |

**当场自救三步**：
1. 重复一遍问题（争取 5 秒思考时间）
2. 说"这个问题分两层"
3. 先答你有把握的那一层，另一层说"我核对一下文件"

## 9.2 被质疑 AI

| 情形 | 话术 |
|---|---|
| **"这是 AI 写的吧？"** | "我们**确实使用了 AI 辅助**，并已在论文和支撑材料里完整声明。**AI 主要用在〔填：具体环节〕**；模型结构、公式推导、数据核对、结果校验都是我们做的。" |
| **"AI 写的凭什么算你们的？"** | "**我们有五个环节是团队主导的**：〔填：逐项列出〕。**〔填：一个最有力的"自己推导"的例子〕是我们自己推的。**" |
| **"是不是在隐瞒 AI 使用？"** | "没有。**我们在论文里明确写了使用 AI，还附了完整的使用详情**，包括工具版本、使用环节、采纳与修改情况，最后一页有我们队伍的确认。需要的话我现在就共享给您看。" |
| **"AI 用了多少比例？"** | "我们按环节如实填报了：**〔填：N 个环节里 M 个用了〕**。我们没法给一个百分比，因为 AI 是辅助和建议，**核心决策还是我们做的**。" |

## 9.3 被质疑代码

| 情形 | 话术 |
|---|---|
| **"共享一下代码"** | "好的，这部分由我们的**编程手**来展示。"（**只共享单个代码文件窗口，不要共享整个桌面**） |
| **"这段代码什么意思？"** | （编程手）"这是……（说主流程）。**具体到这一行的实现细节，是 AI 辅助生成的，我们能说清它的作用是……**" |
| **"你们根本看不懂代码吧？"** | "坦率说，**代码里一些高级的实现细节我们理解得不深**。但我们能说清每个脚本的**输入、处理流程和输出**，也能看懂**模型对应的那部分代码**，而且**有一套独立的校验程序**能验证结果的正确性。" |
| **"这个函数是干什么的？"** | （编程手）"这个是用来……（说功能）。**如果老师想了解具体实现，我可以打开对应的部分。**" |
| **"为什么用这个数据结构？"** | （编程手）"这里用的是〔填：数据结构〕，好处是……。**逻辑和论文里的判断一致，只是实现更高效。**" |

**共享前必做**：关掉聊天窗口、邮箱、其他代码文件，**只留答辩相关的那一个**。

## 9.4 被质疑结果

| 情形 | 话术 |
|---|---|
| **"结果怎么保证是对的？"** | "**我们有独立的校验程序**：把结果展开，逐格检查有没有任何两个对象占用同一个单元格。**所有结果都通过了校验。**" |
| **"能不能现场验证一下？"** | "可以，**我打开结果文件给您看。**"（**优先打开文件，不要现场跑代码**） |
| **"你们的结果是不是碰运气？"** | "我们做了**多初值检验**：〔填：N 组初值的结果区间〕。另外代码用**固定迭代次数**控制停机，同一输入永远出同一结果——**是可复现的，不是碰运气**。" |
| **"这个数字和那个数字对不上"** | "我核对一下。**（共享文件）**您看，这里写的是……（如实指出）。**确实是我们表述上的疏漏，感谢老师指出。**"（**绝不狡辩**） |
| **"你的结果比理论最优差多少？"** | "理论上界是〔填：数值〕，我们得到〔填：数值〕。**这是可接受时间内的高质量可行解，不是最优性证明——我们在论文里主动标注了这个差距。**" |

## 9.5 设备与技术事故

| 情形 | 话术 |
|---|---|
| **屏幕共享失败** | "老师稍等，我重新共享一下屏幕。"（**提前演练过至少 3 次**，别慌） |
| **网络卡顿/掉线** | "老师，我这边网络有点波动，我重新进一下会议室，**大约需要 30 秒**。"（**立刻重进，别在原地解释**） |
| **麦克风没声音** | "老师听得到吗？"→ 切换设备 → "现在可以了吗？"**提前在系统设置里确认好输入设备**。 |
| **PPT 打不开** | "我用浏览器版本给您看。"（**提前把网页版准备好放在浏览器标签页**） |
| **被要求开摄像头但没准备** | "好的，我开一下。"（**提前确认摄像头可用、背景干净、光线不逆光**） |
| **时间超了被打断** | "好的老师，我直接说结论——〔填：一句话核心结论〕。"（**永远准备一个 30 秒的极简版**） |

## 9.6 时间控制

| 情形 | 话术 |
|---|---|
| **自述超时** | 立刻跳到结论："我们最终的结果是〔填：核心数字〕，全部通过校验。以上是我们的汇报。" |
| **被要求展开讲某页** | "好的，这一页的核心是……"（**只讲那页，别扩散**） |
| **被问"还有补充吗"** | "补充一点：**我们主动交代的不足是〔填：一条〕**，这是我们后续想继续做的方向。" |
| **答辩结束了想再争取一下** | "谢谢各位老师。**如果需要，我们可以补充演示校验程序。**" |

## 9.7 心态与纪律（三个人都要记住）

1. **不抢答**：谁负责哪块，提前分工好，不越界回答
2. **不打断评委**：让他把话说完，哪怕他说错了
3. **不说"我们觉得"**：改说"我们的模型显示""根据文件"
4. **不情绪化**：被批评就说"感谢指出"
5. **互相补位**：一个人卡住，另一个自然接"这块我补充一下"
6. **手边三样东西**：这一页话术表、核心数字卡、结果文件所在的文件夹
