# 一、答辩流程与当天准备

> 线上答辩的形式各校略有差异，**先确认自己学校的具体要求**，再按本文准备。

---

## 1.1 常见答辩形式（开会前一定问清）

| 项目 | 常见情况 | 你要确认的 |
|---|---|---|
| 平台 | 腾讯会议 / 钉钉 / Zoom / 学校自建 | 提前装好、登录、测试音频 |
| 自述时长 | 8 / 10 / 15 分钟 | **精确到分钟**，按最长的准备 |
| 问答时长 | 5–15 分钟 | 问题大概几个 |
| 是否共享屏幕 | 通常需要 | 提前演练 |
| 是否开摄像头 | 各校不同 | 若需要，提前调好角度与光线 |
| 是否全员在场 | 通常三人都在 | 确认每人都有设备 |
| 是否可看材料 | 通常可以 | 想清楚哪些能共享 |

**必问的三句话**（发给带队老师或组委会）：
1. "自述时间是多少分钟，问答时间是多少分钟？"
2. "需要共享屏幕吗？需要开摄像头吗？"
3. "有没有需要提前提交的材料（PPT / 纸质版 / 电子版）？"

---

## 1.2 材料清单（提前一天备好）

- [ ] **论文终稿 PDF**（命名为「题号_队号_论文.pdf」）
- [ ] **答辩 PPT / 网页演示**（同时准备 PPT 与 HTML 两个版本，互为备份）
- [ ] **支撑材料压缩包**（代码、结果文件、AI 使用详情表）
- [ ] **结果文件**（能现场打开给评委看的那几个）
- [ ] **独立校验程序**（能证明结果无冲突的那个脚本）
- [ ] **核心数字速记卡**（打印出来放手边）
- [ ] **应急话术表**（打印出来放键盘旁）
- [ ] **自述讲稿**（打印或放第二屏）

---

## 1.3 设备检查（当天提前 40 分钟）

### 网络
- [ ] 优先**有线网**；WiFi 保证 5GHz 频段
- [ ] **关闭所有占带宽的程序**：网盘同步、下载、视频、其他会议软件
- [ ] 手机开 4G/5G 热点作为**备用网络**
- [ ] 路由器重启一次

### 音频
- [ ] 用**耳机**（避免回声），提前试麦
- [ ] 在系统设置里确认**输入设备**选对
- [ ] 关闭系统通知音、聊天软件提示音

### 画面
- [ ] 屏幕分辨率设为**最高**（共享文字才清楚）
- [ ] **关闭桌面所有无关窗口、聊天软件、邮箱**
- [ ] 把要共享的窗口**单独拉出来**，不要共享整个桌面
- [ ] 关掉会弹窗的软件（微信、钉钉、日历提醒）
- [ ] 桌面壁纸换成纯色（避免花哨）

### 环境
- [ ] 背景干净、光线不逆光（背光会变成黑影）
- [ ] 家人/室友知会一声，别突然进来
- [ ] 手机静音但放旁边（备网络）

---

## 1.4 屏幕共享策略（关键）

**要共享的**：
- 论文 PDF（翻到关键页）
- 结果文件（Excel / CSV）
- 校验程序运行时（**只有被要求时才跑**）

**绝不共享的**：
- 整个桌面
- 聊天软件窗口
- 与本场答辩无关的任何文件
- 代码编辑器里未整理的其他文件

**推荐做法**：提前把要展示的文件在浏览器或 PDF 阅读器里**按顺序排好**，答辩时直接翻。

---

## 1.5 答辩流程与各自任务

| 阶段 | 时长 | 主讲 | 其他人做什么 |
|---|---|---|---|
| 开场问候 | 10 秒 | 主讲 | 摄像头前保持端正 |
| 自述汇报 | 8–10 分钟 | 主讲 | 同步翻页、记录评委表情 |
| 评委提问 | 5–15 分钟 | **按分工谁熟谁答** | 谁答谁开麦，其他人翻文件待命 |
| 补充说明 | 1 分钟 | 主讲 | —— |
| 致谢退出 | 10 秒 | 主讲 | —— |

**约定一个"接不上的信号"**：比如主讲停顿时看一眼指定的人，那个人立刻接话。**不要出现三个人同时沉默 5 秒以上。**

---

## 1.6 自述前 5 分钟做什么

1. 深呼吸三次
2. 把讲稿第一段读一遍（**只需要第一段**）
3. 确认麦克风、摄像头、共享窗口
4. 把核心数字卡摆在视线可及处
5. **不要在最后 5 分钟改 PPT**

---

## 1.7 常见扣分点（避坑）

| 扣分行为 | 怎么避免 |
|---|---|
| 超时被强行打断 | 按最长时长准备，留 1 分钟余量 |
| 念稿子不看镜头 | 讲稿写成关键词提纲，不是逐字稿 |
| 被打断就慌 | 提前演练"被打断后直接说结论" |
| 三个人互相抢答 | 提前分工到题，不越界 |
| 数字说错 | 手边放速记卡，不确定就翻 |
| 说"我们不记得了" | 改说"我核对一下文件" |
| 共享屏幕出现无关内容 | 提前清理，只共享单个窗口 |
| 对评委的质疑辩解 | 先说"感谢指出"，再解释 |
