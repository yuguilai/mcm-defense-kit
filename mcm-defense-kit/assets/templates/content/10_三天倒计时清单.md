# 十、答辩前三天 / 一天 / 当天清单

> **打印这一页，做一项划一项。** 不要凭记忆，会漏。

---

## D-3：内容定型日

**目标：把所有要背的东西定下来，之后不再改内容。**

- [ ] 自述讲稿定稿，**计时读三遍**（每遍记录用时）
  - 第一遍：___ 分 ___ 秒
  - 第二遍：___ 分 ___ 秒
  - 第三遍：___ 分 ___ 秒
- [ ] 讲稿按**最长时长**准备，并写好**删减版**（哪些页可以跳）
- [ ] 核心数字速记卡：**手抄一遍**（手写记得牢）
- [ ] 评委问题库过一遍，把 ★★★ 的题标注出来
- [ ] 三人分工表定稿，**明确谁答哪类题**
- [ ] 把论文里的关键页码贴上便利贴（现场好翻）

**今天不碰**：PPT 排版、代码改动

---

## D-2：演练日

**目标：把"说"练成肌肉记忆。**

- [ ] **完整走一遍自述**（对着摄像头，录屏回看）
  - 看回看时记录：哪里卡壳、哪里语速太快、哪里在念稿
- [ ] 三人**互相提问**，每人从问题库随机抽 10 题
- [ ] 演练**"不会的题"**：每人负责一类，练接手
- [ ] 演练**共享屏幕**流程（至少 3 次）
- [ ] 演练**被打断**：别人中途打断，主讲立刻跳到结论
- [ ] 检查 PPT / 网页版**在答辩用的那台电脑上**能正常打开

**必须解决**：任何卡壳超过 5 秒的地方，改讲稿

---

## D-1：技术与物料日

**目标：排除一切技术风险。**

- [ ] **设备全流程演练**（提前 40 分钟的所有检查项走一遍）
- [ ] 测试答辩平台：登录、进会议室、共享屏幕、开麦、开摄像头
- [ ] 准备**备用方案**：
  - [ ] 手机热点
  - [ ] 第二台设备（平板/手机装好会议软件）
  - [ ] PPT 与 HTML 两个版本都拷到 U 盘
- [ ] 打印：讲稿、速记卡、应急话术表、这份清单
- [ ] 桌面清理：关掉所有无关窗口、换纯色壁纸
- [ ] 手机静音、关闭电脑通知
- [ ] 早睡（**比熬夜改 PPT 重要得多**）

**今天不碰**：论文内容、代码逻辑

---

## D-0：当天

### 提前 60 分钟
- [ ] 吃好饭，别空腹也别吃太饱
- [ ] 上厕所
- [ ] 手机充上电

### 提前 40 分钟
- [ ] 开启所有设备，**先于所有人进入会议室**
- [ ] 网络检查（有线优先）
- [ ] 音频检查：耳机 + 试麦
- [ ] 画面检查：分辨率最高、背景干净、光线不逆光
- [ ] 关闭：网盘、下载、聊天软件、邮箱、系统通知
- [ ] 打开待展示的文件，排好顺序

### 提前 15 分钟
- [ ] 三个人都到位，**再对一次分工**
- [ ] 讲稿第一段读一遍
- [ ] 深呼吸
- [ ] 水杯放手边（但别喝太多）

### 答辩中
- [ ] 主讲看镜头，不盯着屏幕念
- [ ] 谁答谁开麦，**不要同时开麦**
- [ ] 记录评委的问题（**方便复盘和补答**）
- [ ] 时间过半时看一下计时

### 答辩后
- [ ] 立刻复盘：哪些答得好、哪些答砸了
- [ ] 把没答上的问题整理出来
- [ ] 如果有补交材料的要求，当天就弄
