# 八、三人分工与各自准备清单

> **核心原则**：**每类问题有明确的第一答手，另外两人负责补位。**
> 不要出现"三个人都答"或"三个人都不答"。

---

## 8.1 角色定义

| 角色 | 负责范围 | 核心能力要求 |
|---|---|---|
| **建模手（A）** | 模型设计、公式推导、假设合理性、创新点 | 能说清**每一步为什么这么做** |
| **编程手（B）** | 算法实现、代码逻辑、数据结构、复杂度 | 能说清**每个脚本的输入输出与主流程** |
| **论文手（C）** | 论文结构、图表、摘要、写作规范、AI 声明 | 能说清**论文的组织逻辑与每张图的来源** |

**三个人都必须能**：
- 讲完整自述（以防有人掉线）
- 说清自己那部分的核心数字
- 回答"这篇论文最核心的创新是什么"

---

## 8.2 分工表（把名字填进去）

| 问题类型 | 第一答手 | 第二答手 | 备注 |
|---|---|---|---|
| 模型 / 公式 / 假设 | 〔填〕 | 〔填〕 | |
| 算法 / 代码 / 实现 | 〔填〕 | 〔填〕 | 被要求共享代码时由此人操作 |
| 论文 / 图表 / 写作 | 〔填〕 | 〔填〕 | |
| 结果数字 | 〔填〕 | 〔填〕 | 谁记数字最准谁上 |
| AI 使用情况 | 〔填〕 | 〔填〕 | **建议固定一人**，口径统一 |
| **"不会的题"** | 〔填〕 | 〔填〕 | **必须预先指定** |

---

## 8.3 建模手准备清单

- [ ] 能背出**核心模型的完整逻辑链**（从假设到公式到结论）
- [ ] 每个公式都能说清：**是什么 / 为什么 / 怎么用**
- [ ] 每个假设都能说清：**为什么要这个假设 / 去掉了会怎样**
- [ ] 能回答"如果换成另一种建模方式会怎样"
- [ ] 能说清**三个创新点**，每个都能展开 30 秒
- [ ] 能说清**两条不足**，并给出改进方向
- [ ] 熟记 7.1 的全部数字

**最可能的追问**：
- "这个假设合理吗？有什么依据？"
- "为什么用这个方法而不是那个？"
- "这个模型有什么局限性？"

---

## 8.4 编程手准备清单

- [ ] 能说清**每个脚本的三件事**：输入 / 处理流程 / 输出
- [ ] 能说清**主流程的伪代码**（不需要背真实代码）
- [ ] 准备好**论文公式 ↔ 代码位置对照表**
- [ ] 能手写或口述**关键判断条件的实现逻辑**
- [ ] 准备好**校验程序的运行结果**（提前跑好存成文本）
- [ ] 演练过**共享屏幕展示代码**（至少 3 次）
- [ ] 知道**哪些部分是 AI 辅助生成的**，并能说清其作用

**最可能的追问**：
- "这段代码什么意思？"
- "为什么用这个数据结构？"
- "时间复杂度是多少？"
- "如果数据量大 10 倍会怎样？"

---

## 8.5 论文手准备清单

- [ ] 能说清**论文的整体结构**（每一章讲什么）
- [ ] 能说清**每张图的来源**（数据从哪来、用什么画的）
- [ ] 熟记**摘要**（很多评委会拿摘要提问）
- [ ] 能说清**参考文献**的分布与核心文献
- [ ] 能说清 **AI 使用声明**的完整内容
- [ ] 准备好**论文与支撑材料的对应关系**

**最可能的追问**：
- "摘要里的数字和正文对得上吗？"
- "这张图是怎么画的？"
- "参考文献够不够新？"

---

## 8.6 三人协同演练（D-2 必做）

### 演练一：接力回答
> 一个人回答时，另外两人**不许插话**。答完，主讲问"还有补充吗"，另一人再接。

### 演练二：接手"不会的题"
> 随机抽一道没人准备的题，**由指定的人接**，另外两人立刻低头翻文件（做出核对的样子）。

### 演练三：被打断
> 主讲说到一半，另一人打断："时间不够了，直接说结论。"主讲必须立刻跳到结论。

### 演练四：紧急替补
> 假设主讲掉线，**另一个人能不能接着讲下去？**（每个人都要练完整自述）

### 演练五：共享屏幕
> 实操一遍：选窗口 → 翻页 → 放大 → 关闭。**至少 3 遍。**

---

## 8.7 现场分工纪律

| 场景 | 谁说话 | 其他人 |
|---|---|---|
| 自述 | 主讲 | 静音、记录评委反应 |
| 模型问题 | 建模手 | 翻文件待命 |
| 代码问题 | 编程手 | 翻文件待命 |
| 数字问题 | 谁记得谁答 | 立刻在速记卡上找 |
| AI 问题 | **固定那一人** | 保持沉默，不抢答 |
| 都不会 | **指定的那个人** | 低头翻文件 |

**三条铁律**：
1. **不抢答**——不是你的范围就别开口
2. **不拆台**——队友说错了，等他答完再补"我补充一点"
3. **不沉默**——有人卡住超过 3 秒，指定的人立刻接

## 8.8 每个人都要背的一句话

| 角色 | 一句话 |
|---|---|
| 建模手 | "我们的模型是〔填〕，核心创新是〔填〕。" |
| 编程手 | "代码分〔N〕个脚本，主流程是〔填〕。" |
| 论文手 | "论文分〔N〕章，核心结论是〔填〕。" |
| 全体 | "**我们愿意对论文的每一个结论负责。**" |
