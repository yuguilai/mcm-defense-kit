# 十、三天倒计时清单

> **打印这一页，做一项划一项。** 三个人各拿一份。
> 我们是**线下答辩** —— 除了内容，还要留出**跑场地、试投影**的时间。

---

## D-3 · 内容关（最重要的一天）

### 全员

- [ ] 三个人各自**完整读一遍论文**（不用逐字，重点看摘要、假设、四问的结论）
- [ ] 三个人各自**完整读一遍 [02_自述讲稿](02_自述讲稿.md)**
- [ ] 一起讨论确认：**「我们最核心的创新是什么」**，统一成一句话
- [ ] 一起讨论确认：**「我们的不足是什么」**，统一成三条

### 张三（问题一、问题二）

- [ ] 背出四个相关系数：**−0.913 / +0.419 / +0.276 / −0.191**
- [ ] 能解释负号含义：**"总量越少，短缺越严重"**
- [ ] 能现场手算权重：`0.913 / 1.608 = 0.57`
- [ ] 能现场手算 **1999 年**：`0.57×10 + 0.26×6 + 0.17×10 = 8.96`
- [ ] 能现场手算 **1985 年**：`0.57×5 + 0.26×3 + 0.17×3 = 4.14`
- [ ] 能说清**为什么剔除工业用水**（含对照权重 0.51/0.23/0.11/0.15）

### 李四（问题三、问题四）

- [ ] 背出预测值：**2001 → 7.75，2002 → 7.80**
- [ ] **能主动说出 R² = 0.0694**，并解释"只做区间判断"
- [ ] 统一口径：**只说"仍处于高风险区间"，绝不说"上升"**
- [ ] 能说清**措施与相关系数符号的对应**（负相关→开源，正相关→节流）
- [ ] 能说清 30% 目标的依据（1985 年占比约 32%）

### 王五

- [ ] 熟悉附录 1/2/3 的内容，能快速定位任意一行
- [ ] 背熟"**方法太简单**"的应答话术
- [ ] 背熟"**68% vs 59.1%**"的应答话术
- [ ] 准备数据来源应答：赛题附表 + 《北京 2009 统计年鉴》

## D-1 · 演练关（最累但最有效）

### 上午：模拟提问

- [ ] 用 [06_评委问题库](06_评委问题库.md) 的 ★★★ 题随机提问
- [ ] **必练这三道**：
  1. "R² 只有 0.0694，模型还有意义吗？"（李四）
  2. "论文里 68% 和 59.1% 到底哪个对？"（王五）
  3. "你们这个方法是不是太简单了？"（张三）
- [ ] **手机录像回看** —— 看小动作、语速、有没有一直低头

### 下午：场地实测

- [ ] **去实际答辩场地**（或类似教室）
- [ ] 试投影：分辨率、比例、字号（**站最后一排看**）
- [ ] 试站位：不要站在投影光路里
- [ ] 试音量：不靠麦能不能让后排听清
- [ ] **完整走一遍 PPT 翻页**（用翻页笔）
- [ ] 确认黑板能不能用（能用的话，练一下**在白板上写公式**）

### 晚上：定稿

- [ ] 三个人各讲一遍完整自述，计时
- [ ] **确认 R² 和 68.2% 两个口径全员一致**
- [ ] 检查 PPT 里的数字与速记卡是否一致
- [ ] 早睡

## D-0 · 上场关

### 出发前

- [ ] 文件袋（论文 3 份 + 附录 3 张 + 速记卡 + 话术表 + 讲稿）
- [ ] 2 个 U 盘
- [ ] 笔记本电脑 + 电源 + 转接头
- [ ] 翻页笔
- [ ] 手机满电（备用）
- [ ] **穿正装 / 整洁衣服**

### 到场后（提前 40 分钟）

- [ ] **试投影**（如果还没试过）
- [ ] 确认**站位**，不要挡投影
- [ ] 把**讲台三件套**摆好：速记卡、话术表、讲稿提纲
- [ ] **三张附录表放在手边**（能一把抽出来）
- [ ] 关掉手机所有通知音
- [ ] 上洗手间

### 上场前 5 分钟

- [ ] 深呼吸三次
- [ ] **只读讲稿的第一段**
- [ ] 默念三条：
      1. **我们不藏东西** —— R²、档位、无低风险年，都主动说
      2. **我们的数字都能复核** —— 附录全列出来了
      3. **方法简洁是有意的** —— 用户是基层水务部门
- [ ] 不要在最后 5 分钟改 PPT
