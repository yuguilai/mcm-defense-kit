# 示例：水资源短缺风险综合评价

这是一份**真实跑通**的答辩手册示例，可用于：

- 直观了解 skill 会产出什么
- 直接复制结构，改成你自己的赛题
- 复现 README 与 [在线演示](https://yuguilai.github.io/mcm-defense-kit/) 的效果

## 材料背景

| 项 | 内容 |
|---|---|
| 赛题 | 水资源短缺风险综合评价（北京市 1979–2000 年数据） |
| 论文 | 《北京市水资源短缺风险综合评价数学模型》 |
| 答辩形式 | 校内选拔 · 线下 |
| 团队 | 张三 · 李四 · 王五（化名示例） |
| 技术栈 | **仅 Excel**（无编程语言） |

## 这份手册的看点

- **数据定权重**：用 Excel `CORREL` 算出三个因子与短缺量的相关系数，按 \|r\| 归一化打分 → `0.57 / 0.26 / 0.17`
- **风险因子双向性**：农业用水正相关、水资源总量负相关，同一模型里方向不同
- **建模到公文闭环**：从综合评价走到防控建议报告
- **论文瑕疵处理**：复算发现正文「59.1%」是笔误（逐行统计实为 68.2%），手册给出了统一口径话术
