# 九、答辩应急话术（按场景查表）

> **用法**：把这一页单独打印，**放在讲台上**。出事的时候不要思考，直接念。
> 我们是**线下答辩**，没有网络问题，但有投影和现场状况 —— 按线下场景写。

---

## 9.1 被问不会的问题

| 情形 | 话术 |
|---|---|
| **是数据问题** | "具体数字我手上的附录表里有，**我翻一下**。（翻出附录 1/2/3）" |
| **是模型问题，框架清楚但细节忘了** | "这个问题的核心是……（说框架）。**具体数值我对照附录核对一下。**" |
| **真的完全不会** | "老师，**这个问题我们目前的理解是……**（说你知道的部分）。**如果理解有偏差，还请老师指正。**" |
| **三个人都不会** | "这个问题我们**确实没有深入考虑**，感谢老师指出。**我们能确认的是：我们的核心结论建立在可复核的数据上。**" |
| **被追问"你到底懂不懂"** | "模型和思路我们是清楚的；**具体到某些技术细节，我们理解得不够深**。但结果是可以独立复核的。" |
| **问的问题听不懂** | "抱歉老师，**能不能请您再说明一下问题的重点？** 我想确认我理解得对。"（**这不丢分，答错才丢分**） |

**当场自救三步**：
1. 重复一遍问题（争取 5 秒思考时间）
2. 说"这个问题分两层"
3. 先答你有把握的那一层，另一层说"**我核对一下材料**"

## 9.2 被质疑 AI

| 情形 | 话术 |
|---|---|
| **"这是 AI 写的吧？"** | "我们**确实使用了 AI 辅助**，并已在论文和支撑材料里完整声明。**AI 主要用在语言润色和格式检查**；相关性分析、权重计算、评分打分、结果核对都是我们自己做的。" |
| **"AI 写的凭什么算你们的？"** | "**核心工作是我们自己完成的**：相关系数是用 Excel 的 `CORREL` 函数算的，权重是按 `|r|/Σ|r|` 算的，打分档位是我们三个人一起逐条讨论定的，建议报告是我们自己写的。" |
| **"是不是在隐瞒 AI 使用？"** | "没有。**我们在论文里明确写了使用情况，还附了完整的使用详情**，包括工具、环节和确认签名。需要的话我可以给您看。" |
| **"AI 用了多少比例？"** | "我们按环节如实填报了。**没法给百分比**，因为 AI 是辅助和建议，**核心判断还是我们做的**。" |

> ⚠️ **千万别说"没用 AI"** —— 如果论文里提交了 AI 使用详情，评委会对照，当场露馅最致命。

## 9.3 被质疑"方法太简单 / 没创新"

> ★ **这是我们的头号风险点，必须背熟。**

| 情形 | 话术 |
|---|---|
| **"你们这方法也太简单了吧？"** | "**简洁是刻意的设计。** 这份研究的用户是**基层水务管理部门** —— 方法必须他们自己能复现。我们用 Excel 的 `CORREL` 和趋势线，**任何会用表格的人都能上手、能自己更新数据**。" |
| **"用 Excel 算这个，是不是偷懒？"** | "恰恰相反。**数据规模是 22 年 × 5 个指标，计算量本身很小** —— 用 Excel 完全胜任，而且更透明。**我们的目标是让方法真正被用起来，不是展示技术。**" |
| **"你们学计算机的怎么不写代码？"** | "我们会编程。但**这道题用 Excel 是最优解** —— 不是因为不会，而是因为**对这个用户群体最合适**。" |
| **"创新点在哪里？"** | "三条：**① 权重完全由相关系数归一化得出，不掺主观**；**② 发现了风险因子的双向性** —— 总量是负相关要保、农业是正相关要压，调控方向相反；**③ 从建模到公文的完整闭环**。" |
| **"别人也能这么做吧？"** | "**方法本身确实不复杂，但'从相关系数的符号读出管理方向'这一步是我们的判断。** 同类论文往往只报告相关系数的大小，没有指出正负号的管理含义。" |
| **"简单的方法结论可靠吗？"** | "**我们的结论建立在排序上，不是绝对数值上。** 附录 2 和附录 3 把系数、权重、评分全部列出 —— **每一个数字都可以追溯、可以复核**。" |

## 9.4 被质疑结果

| 情形 | 话术 |
|---|---|
| **"结果怎么保证是对的？"** | "**附录 2 和附录 3 把全部计算过程列出了。** 相关系数、权重、每年的分项打分和总分都逐行可见，**任何一个数都可以自己验算。**" |
| **"能不能现场验证一下？"** | "可以，**我用 1999 年举例**：生活 10 分、农业 6 分、总量 10 分，代入 `0.57×10 + 0.26×6 + 0.17×10 = 8.96`，与附录 3 一致。"（**能在白板上写最好**） |
| **"你们的结果是不是碰运气？"** | "**完全可复现。** 用同样的数据和公式，任何人在 Excel 里输入 `CORREL` 都会得到同样的 −0.913。" |
| **"这个数字和那个数字对不上"** | "我核对一下。（**翻纸质附录**）您看，这里是……（如实指出）。**确实是我们整理时的疏漏，感谢老师指出。**"（**绝不狡辩**） |
| **"摘要 68%、正文 59.1%，到底哪个对？"** | "**68.2% 是正确的，摘要是对的。** 按附录 3 逐行统计：中风险 8 年、高风险 7 年，合计 15 年，15÷22 = 68.2%。正文的 59.1% 是我们整理时的一处笔误，**我们赛后复核时已经发现了。**" |
| **"为什么 22 年一个低风险都没有？"** | "**这是数据本身反映的。** 历史最低是 1985 年的 4.14 分，落在中风险区间。当年总用水量 31.71 亿方，仍然超过了水资源总量 38 亿方 —— **条件最好的年份也是缺水的。**" |

## 9.5 被质疑数据

| 情形 | 话术 |
|---|---|
| **"数据从哪来的？"** | "赛题附表的 1979–2000 年数据，以及《北京 2009 统计年鉴》。**附录 1 把 22 年原始数据完整列出了。**" |
| **"短缺量怎么会有负数？"** | "**负值代表当年供大于需，是丰水年。** 比如 1987 年是 −7.71，1996 年是 −5.86。这是正常的水文现象，**也说明我们用的是原始数据，没有做人为修正。**" |
| **"22 年够吗？"** | "对相关分析和短期趋势判断是够的。**n=22 时，显著性水平 0.05 下的相关系数临界值约是 0.42** —— 我们的水资源总量 |r| = 0.913，远超这个门槛。" |
| **"数据有误差怎么办？"** | "我们假设赛题数据真实可靠，这写在模型假设的第 1 条里。**如果存在系统误差，会同时影响所有年份，对相对排序的影响有限。**" |

## 9.6 被质疑预测（问题三专项）

> ★ **这题最容易被抓，李四必须背熟。**

| 情形 | 话术 |
|---|---|
| **"R² 只有 0.0694，模型还有意义吗？"** | "**我主动说明这个数字：0.0694 确实很低**，年份只能解释 6.94% 的变化。**所以我们不把它当精确预测工具**，只做**方向性判断** —— 未来两年仍处于高风险区间。" |
| **"你说上升，可 7.75 比 2000 年的 8.70 低啊？"** | "老师您观察得很仔细。**我们的结论聚焦在区间判断上**：7.75 和 7.80 都落在 6 到 8 之间，**仍属高风险区间**。考虑到 R² 很低，**我们不做过强的趋势断言。**" |
| **"为什么不预测五年十年？"** | "题目要求是两年。而且**线性回归适合短期外推** —— 时间越长，越可能发生结构性变化（南水北调通水、产业调整），**加上 R² 只有 0.0694，外推越远越不可靠。**" |
| **"为什么不用 ARIMA？"** | "**样本量不够。** ARIMA 通常需要 50 个以上观测点，我们只有 22 个，参数估计不稳定。**一元线性回归更透明，也符合这道题做趋势判断的定位。**" |
| **"R² 低是谁的锅？"** | "**是数据本身的特点。** 北京的水资源短缺受降水量年际变化影响很大，而降水波动剧烈、没有明显线性趋势。**这不是方法的问题。**" |

## 9.7 现场与技术事故（线下专属）

| 情形 | 话术 / 动作 |
|---|---|
| **投影连不上** | "老师稍等，我换一个接口 / 用备用线。"（**随身带转接头，提前到场试过**） |
| **投影显示不全（比例不对）** | "我调一下投影模式。"（**提前演练过，切"复制"模式**） |
| **PPT 打不开** | "我用 PDF 版本给您看。"（**提前把 PPT 导出成 PDF，手机和 U 盘各一份**） |
| **字体变乱码 / 排版错位** | "我用 PDF 版打开，格式是固定的。"（**PDF 是最稳的兜底**） |
| **翻页笔失灵** | 直接用键盘方向键，或**请队友帮忙翻页**。（队友提前坐在电脑旁） |
| **被要求写字但黑板不够** | 简明写核心式子：`0.57×10+0.26×6+0.17×10=8.96` |
| **时间超了被打断** | "好的老师，我直接说结论 —— **中高风险占 68.2%，未来两年仍在高风险区间**。以上是我们的汇报。" |
| **有人说错了被评委抓住** | **不要当场纠正队友**。等节奏缓一下："我补充一点……"然后**用正确说法覆盖**，不点破。 |
| **评委之间意见不一致** | "两位老师的角度我们都记下了。从我们模型的角度，我倾向于……但确实老师提到的因素我们考虑得不够。" |

> 💡 **线下最大的优势**：翻纸质材料**比翻电脑快得多**。所以**三张表一定打印、贴标签、放讲台**。

## 9.9 心态与纪律（三个人都要记住）

1. **不抢答**：谁负责哪块提前分工，不越界
2. **不打断评委**：让他把话说完，哪怕他说错了
3. **不说"我们觉得"**：改说"我们的模型显示""根据附录"
4. **不情绪化**：被批评就说"**感谢老师指出**"
5. **互相补位**：一个人卡住，另一个自然接"我补充一点"
6. **手边三样东西**：
   - 这一页话术表（打印）
   - 核心数字速记卡（打印）
   - **附录 1 / 2 / 3 三张打印表**（贴好标签，装文件袋）
