## 我们的核心数字（一屏记住）

| 指标 | 数值 |
|---|---|
| 数据区间 | **1979–2000 年**，共 **22 年** |
| 水资源总量相关系数 | **−0.913**（极强负相关，第一风险因子） |
| 农业用水相关系数 | **+0.419**（中等正相关，第二风险因子） |
| 生活用水相关系数 | **+0.276**（弱正相关，第三） |
| 工业用水相关系数 | **−0.191**（最弱，已剔除） |
| 三项权重 | **0.57 / 0.26 / 0.17** |
| 风险等级阈值 | 极高 ≥8；高 6–8；中 3–6；低 <3 |
| 中高风险年份占比 | **68.2%**（15 / 22 年） |
| 历史最高风险分 | **8.96**（1999 年） |
| 历史最低风险分 | **4.14**（1985 年） |
| 无低风险年份 | **22 年全部 ≥ 中风险** |
| 预测 2001 / 2002 | **7.75 / 7.80**（高风险区间） |
| 线性回归 R² | **0.0694**（趋势弱，波动大） |

> ⚠️ **68.2% 这个数要背准**。论文摘要里写的 68% 是对的，正文里出现的 59.1% 是笔误。我们已按逐行统计核实过。

## 一条主线（讲稿里要用）

> **「识别因子 → 评价风险 → 预测趋势 → 给出建议」——从数据出发，把北京市 22 年的水资源账算清楚，最后落到一份能直接交给水务部门的报告上。**

四个问题不是四个孤立任务，是**同一条决策链的四步**：问题一找出"病根"（水资源总量不足 + 农业用水过多），问题二把"病情"量化成分数和等级，问题三判断"下一阶段走势"，问题四开出"处方"并写成公文。

---

## 三个创新

1. **权重完全由数据决定，不掺主观**
   很多同类做法用 AHP 层次分析法，要专家打分，主观性强。我们直接用**相关系数的绝对值归一化**得到 0.57 / 0.26 / 0.17 —— 相关性强的因子自然权重大，全程可复现。

2. **风险因子的"双向性"识别**
   我们发现相关系数**有正有负**，这本身就是结论：水资源总量是 −0.913（总量越少越危险），农业用水是 +0.419（用得越多越危险）。**一个要"保"、一个要"压"**，调控方向完全相反 —— 这直接决定了问题四的措施结构。

3. **从建模到公文的完整闭环**
   问题四不是泛泛谈建议，而是**以水行政主管部门为收件人**写了一封结构完整的建议报告：明确核心风险 → 呈现评价结果 → 预警短期趋势 → 提出落地措施 → 给出预期效果。这在同类论文里不多见。

## 两条不足（主动说，别等评委挖）

1. **打分档位是人工设定的**
   问题二里"用水量 >11 亿方记 10 分、>10 亿方记 9 分"这类档位，是我们根据数据分布人工划的，带一定主观性。
   **应对**：承认这点，同时说明——**档位只影响分数的绝对高低，不影响年度之间的相对排序**，所以风险等级的变化趋势是稳的。

2. **线性回归预测能力有限**
   问题三的 R² 只有 **0.0694**，说明风险总分的线性趋势很弱、年度波动大。
   **应对**：**主动讲出 R² = 0.0694**，然后说明我们的结论只取"仍处于高风险区间"这个方向性判断，**不外推具体数值**。
