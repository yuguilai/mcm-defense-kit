# 八、三人分工与各自准备清单

> **核心原则**：**每类问题有明确的第一答手，另外两人负责补位。**
> 不要出现"三个人都答"或"三个人都不答"。

---

## 8.1 角色定义

**我们的分工是"按问题分"** —— 不是按传统建模手/编程手/论文手分，而是按论文的四个问题分。

| 角色 | 负责范围 | 核心能力要求 |
|---|---|---|
| **张三**（主讲） | **问题一、问题二** —— 因子识别、相关系数、权重、风险评分与等级划分 | 能说清**每个数字是怎么算出来的** |
| **李四** | **问题三、问题四** —— 线性回归预测、建议报告与防控措施 | 能说清**R² 为什么低、措施为什么这么设计** |
| **王五** | **数据核对 + 方法质疑应答 + 材料管理** | 能快速翻到附录任意一行；能应对"方法太简单"这类质疑 |

**三个人都必须能**：
- 讲完整自述（**以防有人临时上不了场**）
- 说清自己那部分的核心数字
- 回答"**这篇论文最核心的创新是什么**"
- 说出**那三件必须主动交代的事**（R² 低、档位主观、无低风险年）

## 8.2 分工表

| 问题类型 | 第一答手 | 第二答手 | 备注 |
|---|---|---|---|
| **问题一**（因子识别、相关系数） | **张三** | 王五 | 追问数据来源时由王五翻附录 1 |
| **问题二**（权重、打分、等级） | **张三** | 李四 | 追问 Excel 操作时由李四补 |
| **问题三**（回归、预测、R²） | **李四** | 王五 | **R² 那题李四必须熟练** |
| **问题四**（措施、建议报告） | **李四** | 张三 | 追问措施依据时张三补相关系数 |
| **方法质疑**（太简单、创新不足） | **张三** | 全员 | ⚠️ **这是我们的最大风险点** |
| **数据核对**（具体数字、附录） | **王五** | —— | 提前把三张表贴好标签 |
| **AI 使用情况** | **李四** | —— | **口径必须统一，只说一个人** |
| **"不会的题"** | **张三** | 其他人接力 | **必须预先指定，不能临时推** |

## 8.3 张三准备清单（问题一 + 问题二）

- [ ] 能背出**四个相关系数**及其正负：**−0.913 / +0.419 / +0.276 / −0.191**
- [ ] 能解释**负号含义**："总量越少，短缺越严重 —— 负号表示反向变化，不是关系弱"
- [ ] 能现场手算权重：`0.913 / 1.608 = 0.57`
- [ ] 能说清**为什么剔除工业用水**（|r| 最小 + 走势不一致）
- [ ] 能现场手算**1999 年总分**：`0.57×10 + 0.26×6 + 0.17×10 = 8.96` ✅
- [ ] 能现场手算**1985 年总分**：`0.57×5 + 0.26×3 + 0.17×3 = 4.14` ✅
- [ ] 能背出四个等级阈值：**8 / 6 / 3**
- [ ] 能说清**68.2% 怎么来的**（中风险 8 年 + 高风险 7 年 = 15 年）
- [ ] 能说清**"没有低风险年"怎么解释**（1985 年最低也是 4.14，且当年仍缺水）

**最可能的追问**：
- "相关系数能说明因果吗？"
- "权重为什么是这三个值？"
- "打分档位是你们定的，太主观了吧？"
- "为什么工业用水不算进去？"

---

## 8.4 李四准备清单（问题三 + 问题四）

- [ ] 能背出**预测值**：**2001 → 7.75，2002 → 7.80**
- [ ] **能主动说出 R² = 0.0694**，并解释"趋势弱，所以只做区间判断"
- [ ] ⚠️ **能应对"7.75 比 2000 年的 8.70 低，怎么说上升"** → 统一口径：**只说"仍在高风险区间"，不说"上升"**
- [ ] 能说清**为什么只预测两年**（题目要求 + R² 低不宜外推）
- [ ] 能背出**三个维度**：开源 / 节流 / 管理
- [ ] 能说清**措施与相关系数的对应关系**：
      → 总量 −0.913 负相关 → **开源**（要保）
      → 农业 +0.419 正相关 → **节流**（要压）
- [ ] 能说清**30% 这个目标的依据**（1985 年农业用水占比约 32%，历史出现过）
- [ ] 能说清**预期效果**（高风险 → 中风险）

**最可能的追问**：
- "R² 这么低，这个预测还有意义吗？"
- "你说上升，可 7.75 比 8.70 低啊？"
- "降到 30% 现实吗？"
- "为什么不试试 ARIMA？"

## 8.5 王五准备清单（数据 + 质疑 + 材料）

- [ ] **熟悉附录 1 的 22 年数据**，能快速定位任意年份的任一指标
- [ ] **熟悉附录 2**（相关系数表）和**附录 3**（评分表）
- [ ] 提前把三张表**打印并贴便利贴标签**，装在文件袋里
- [ ] 准备**"方法太简单"的应答**（见下方）
- [ ] 准备**数据来源的应答**："来自赛题附表和《北京 2009 统计年鉴》"
- [ ] 准备**"论文数据不一致"的应答**（68% vs 59.1%）
- [ ] 知道**哪些材料在哪个袋子/哪个位置**

**必备应答 —— 被质疑"方法太简单"**：

> "**简洁是刻意的设计。**
> 这份研究的最终用户是**基层水务管理部门** —— 如果方法复杂到需要专业编程人员才能复现，实用性就大打折扣。我们用 Excel 的 `CORREL` 函数和趋势线，**任何会用表格的人都能上手、能自己更新数据**。
> 而且**简单不等于结论不可靠**：我们的相关系数、权重、评分表在附录里全部列出，**每一个数字都可以追溯来源、可以复核**。
> 我们的重心不是把方法做得复杂，而是**把问题做完整** —— 从识别因子到提出建议，形成了一条完整的决策链。"

## 8.6 协同演练（至少 3 轮）

### 第 1 轮：各自过一遍（D-2）
- 每人独立把自己的部分讲一遍，**计时**
- 找出自己卡壳的地方，记下来

### 第 2 轮：完整走流程（D-2）
- 张三完整自述 10 分钟，另两人当评委
- **李四准备 5 个提问**，王五准备 5 个
- 重点练**交接** —— 张三什么时候把话交给李四

### 第 3 轮：模拟提问（D-1）
- 用 **06_评委问题库**里的 ★★★ 题目随机问
- **必须练这三道**：
  1. "R² 只有 0.0694，模型还有意义吗？"（李四答）
  2. "论文里 68% 和 59.1% 到底哪个对？"（王五答）
  3. "你们这个方法是不是太简单了？"（张三答）
- **录下来回看** —— 会发现很多自己察觉不到的问题（小动作、语速、低头）

### 第 4 轮：全场演练（D-1 或 D-0）
- **去实际场地**（或类似的教室）走一遍
- 测试投影、站位、音量
- 用翻页笔实际翻一遍 PPT

## 8.7 现场纪律（线下答辩特别重要）

| 规则 | 说明 |
|---|---|
| **不抢答** | 一个问题只有一个第一答手。其他人想补充，**等第一答手说完** |
| **不否定队友** | 队友说错了，**不要当场纠正**。等节奏稍缓，说"我补充一点"，然后**用正确说法覆盖**，不要点破 |
| **不交头接耳** | 队友在答时，另外两人**看着队友或评委**，不要低头商量 |
| **不一直看屏幕** | 说话朝**评委席**，不要背对评委操作电脑 |
| **卡壳就接力** | 张三卡住 → 看一眼李四 → 李四立刻接"我补充一点" |
| **手机静音** | 三人全部静音，放桌上不要玩 |
| **纸笔准备好** | 每人一支笔一张纸，**被质疑时记下要点**，回答时可以用 |

**王五**：
> "我管数据和材料 —— 22 年数据、相关系数表、评分表，**评委要核对我随时能翻出来**。方法简单是刻意的，因为用户是基层水务部门。"

## 8.9 掉人预案

> **万一有人临时上不了场**（网络/身体/突发情况），另外两人必须能顶上。

| 情况 | 应对 |
|---|---|
| 张三不能上 | **李四代讲问题一、二**（他已看过），王五管数据 |
| 李四不能上 | **张三代讲问题三、四**，重点保住 R² 和措施依据两个点 |
| 王五不能上 | 张三自己翻表（**提前把三张表放在讲台上**） |
| 只剩一个人 | **一人讲完全部 10 分钟** —— 这也是为什么三个人都要能讲完整自述 |

**所以：D-3 之前，三个人都要完整读过一遍 02_自述讲稿。**
