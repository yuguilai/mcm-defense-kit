# 一、答辩流程与当天准备

> **我们是线下答辩**，形式与线上有本质差异 —— **没有共享屏幕的容错，翻页出错全场都看得见。**
> 这份文档按线下场景写，投影和材料是重点。

---

## 1.1 答辩形式（开始前一定问清）

| 项目 | 我们的情况 | 要确认什么 |
|---|---|---|
| 形式 | **线下答辩** | 教室 / 会议室 / 报告厅 |
| 设备 | 投影 + 讲台电脑 | **用自己的电脑还是主办方的？** |
| 自述时长 | 约 **10 分钟** | 精确到分钟，**按最长准备** |
| 问答时长 | 约 **5 分钟** | 大概问几个问题 |
| 汇报方式 | 投影展示 | 是否需要提前提交 PPT？ |
| 全员在场 | 三人都在 | 确认座位安排 |
| 是否可看稿 | 通常可以 | 带纸质讲稿 |

**必问的三句话**（提前发给带队老师）：
1. "自述多少分钟，问答多少分钟？"
2. "投影是我用自己的笔记本，还是用现场的电脑？**如果是现场电脑，需要提前多久拷文件？**"
3. "有没有需要提前提交的材料（PPT / 论文纸质版）？"

> ⚠️ **线下答辩最容易出问题的是第三条**。如果必须用现场的电脑，你要面对**字体缺失、版本不兼容、公式变乱码**三个风险。**一定要争取提前拷贝并试播一次。**

---

## 1.2 材料清单（提前一天备好）

- [ ] **论文终稿 PDF**（打印 **3 份**，评委一人一份 —— 线下答辩这是加分项）
- [ ] **答辩 PPT**（U 盘 + 邮箱各存一份，互为备份）
- [ ] **数据附表打印版**（附录 1 的 22 年数据、附录 2 的相关系数表、附录 3 的评分表）
      → **评委会想现场核对数字，手上有纸质版就从容得多**
- [ ] **核心数字速记卡**（打印，放在讲台上）
- [ ] **应急话术表**（打印，放在讲台上）
- [ ] **自述讲稿**（打印成**关键词提纲**，不要逐字稿 —— 逐字稿会让人一直低头）
- [ ] **U 盘 2 个**（主备各一）
- [ ] **翻页笔**（如果需要自己翻页，确认电池）

> 💡 **线下答辩的独门武器**：把 **附录 1、2、3 三张表打印出来**，装在文件袋里。
> 评委问到具体数字，你**直接抽出来递过去** —— 这比说"我打开电脑查一下"强太多。

---

## 1.3 设备检查（当天提前 40 分钟到场）

### 投影（线下最关键）

- [ ] **提前到场实测**，不要等到上场才发现问题
- [ ] 确认分辨率 —— 我们的 PPT 是 **16:9**，投到 **4:3 屏幕会上下留黑边**（可接受），但**变形就不可接受**
- [ ] **字号检查**：站在教室**最后一排**看，正文至少能看清
      → 建议**正文字号 ≥ 24pt，标题 ≥ 36pt**，表格 ≥ 18pt
- [ ] 确认**连线方式**：HDMI / Type-C / VGA？**转接头带了没有？**
- [ ] 确认电脑的**投影模式**：扩展 vs 复制（**建议用"复制"**，避免讲者看到的和观众不一致）
- [ ] **关闭屏幕保护、休眠、自动更新**（Windows 的自动更新弹窗是灾难）
- [ ] **关闭所有通知**：微信、QQ、邮件、日历提醒

### 光线与环境

- [ ] 教室灯光：**不要让投影幕布被灯直射**（会发白看不清）
- [ ] 确认自己的站位 —— **不要站在投影光路中间**（会挡投影、脸上有强光）
- [ ] 如果教室大，**试一下音量**：不靠麦能不能让最后一排听清
- [ ] 确认**黑板/白板能不能用** —— 如果能，写公式解释是加分的

### 备用方案

- [ ] 手机里存一份 **PPT 的 PDF 导出**
- [ ] U 盘 2 个
- [ ] 带**自己的笔记本电脑**（即使主办方提供电脑，也带着，以防万一）

## 1.4 投影策略（线下版）

**要展示的**：
- 答辩 PPT（图表、公式、结果表）
- 需要时翻到论文的**附录 1 / 2 / 3**（纸质版递送更好）

**线下答辩的优势 —— 用好板书**：
如果教室有白板，**在被评委追问公式时，直接上去写**。
> 比如评委问"权重怎么来的" → 走到白板前写下 `|−0.913| / 1.608 = 0.57`，比在 PPT 上翻页找**有力得多**。
> **这会让评委觉得你对内容是真熟的，不是背稿。**

**"三张表"随手抽**：
把附录 1（22 年原始数据）、附录 2（相关系数表）、附录 3（评分表）**分别打印、贴便利贴标签**。
被要求核对数字时，**按标签直接抽出来递过去** —— 动作干脆，印象分高。

## 1.5 答辩流程与各自任务

| 阶段 | 时长 | 主讲 | 其他人做什么 |
|---|---|---|---|
| 开场问候 | 10 秒 | 张三 | 两人坐在旁边，坐姿端正 |
| 自述汇报 | 约 10 分钟 | 张三 | 李四负责翻页提示；王五准备翻文件 |
| 评委提问 | 约 5 分钟 | **按分工谁熟谁答** | 谁答谁站起来/前倾；其他人查纸质材料 |
| 补充说明 | 1 分钟 | 张三 | —— |
| 致谢退出 | 10 秒 | 张三 | —— |

**约定一个"接不上的信号"**：
张三答不上来时，**看一眼李四**，李四立刻接"我补充一点"。
**绝对不能出现三个人同时沉默超过 5 秒。**

**线下专属提醒**：
- 答问时**站起来或身体前倾**，不要瘫在椅子上
- 说话**朝评委席**，不要一直看屏幕
- **不要背对评委**操作电脑

---

## 1.6 自述前 5 分钟做什么

1. 深呼吸三次
2. 把讲稿**第一段**读一遍（**只需要第一段**）
3. 确认投影、翻页笔、纸质材料的位置
4. 把**核心数字卡**摆在讲台视线可及处
5. **不要在最后 5 分钟改 PPT**

## 1.7 常见扣分点（避坑）

| 扣分行为 | 怎么避免 |
|---|---|
| **站在投影光路里，脸上一片亮** | 提前试站位，站在幕布**侧前方**，不要站在投影仪前面 |
| 超时被强行打断 | 按最长时长准备，留 1 分钟余量 |
| 念稿子一直低头 | 讲稿写成**关键词提纲**，不是逐字稿 |
| 翻页出错（线下无处可藏） | 提前**完整演练至少 3 次**，包括翻页节奏 |
| 字体在别人电脑上变形 | 提前拷到现场电脑**试播**；PDF 备份 |
| 三个人互相抢答 | 提前分工到题，不越界 |
| 数字说错 | 手边放速记卡，不确定就**翻纸质表** |
| 说"我们不记得了" | 改说"**我核对一下材料**"，然后从容翻表 |
| 对评委的质疑辩解 | 先说"**感谢老师指出**"，再解释 |
| 被追问时慌神、看队友 | 用 6.8 的四步模板：接住 → 说知道的 → 说边界 → 请指正 |

## 1.8 我们的"三个必须主动说"（线下答辩特别重要）

线下没有屏幕可以转移注意力，**眼神一直对着你**，所以在自述里**主动交代**这三件事，比被问出来强得多：

1. **主动说 R² = 0.0694 很低**
   > "我主动说明这个数字：0.0694 是很低的，意味着线性趋势很弱。所以我们只做区间判断，不做精确外推。"
   ⚠️ **这一条最重要** —— 你主动说了，评委就不会觉得你在掩盖。

2. **主动说打分档位是人工设定的**
   > "我们要承认，打分档位是我们根据数据分布人工划的，带一定主观性。但它只影响分数的绝对值，不影响排序。"

3. **主动说没有低风险年份**
   > "22 年里一年低风险都没有 —— 最低的 1985 年也是 4.14 分，落在中风险区间。"

> **主动交代的三件事，会变成信心分；被挖出来的三件事，会变成扣分项。**
